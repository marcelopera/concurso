# Contribuição

Instale as versões indicadas no README. Execute `pnpm install --frozen-lockfile`, `pnpm run build` e `python -m unittest discover -s tests -v` em `sistema-estudo/`. Use dados fictícios nos testes e não adicione catálogos, provas ou bancos de progresso ao Git. Documente mudanças de esquema e verifique se testes não alteraram arquivos versionados.
